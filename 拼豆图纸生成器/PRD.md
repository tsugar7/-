# 拼豆图纸生成器 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
拼豆图纸生成器 (Pixel Bead Pattern Generator)

### 1.2 产品定位
一款免费的在线拼豆图纸生成工具，帮助拼豆爱好者将任意图片转换为像素画风格，并自动匹配 Mard 拼豆色号，生成可打印的图纸和材料清单。

### 1.3 目标用户
- 拼豆手工爱好者
- 像素艺术创作者
- DIY手工制作者
- 需要拼豆图纸的动漫/游戏周边制作者

### 1.4 核心价值
- **简单易用**: 无需专业技能，上传图片即可生成图纸
- **色号精准**: 内置 Mard 291色完整色号库，自动匹配最接近颜色
- **多种尺寸**: 支持 32×32 到 128×128 多种像素尺寸
- **一键导出**: 支持 PNG、PDF 格式导出，含材料清单

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 图片上传
- 支持拖拽上传和点击选择
- 支持格式: JPG、PNG、WEBP、GIF
- 显示图片预览和基本信息(尺寸、大小)
- 支持删除重新上传

#### 2.1.2 像素画转换
- 将图片缩放至目标像素尺寸
- 使用欧几里得距离算法匹配最近色号
- 支持三种色彩模式:
  - 全彩模式: 使用全部 291 种 Mard 色号
  - 常用48色: 适合大多数作品
  - 常用24色: 初学者推荐
- 支持高级调整:
  - 亮度: -50% ~ +50%
  - 对比度: -50% ~ +50%
  - 饱和度: -50% ~ +50%

#### 2.1.3 像素画预览
- 网格形式展示像素画
- 支持缩放查看 (50% - 400%)
- 可选显示网格线
- 可选显示色号标注
- 悬停显示色号、颜色名称、位置信息

#### 2.1.4 色号清单
- 显示所有使用的色号
- 按使用频率排序
- 显示每种颜色的使用数量
- 色块形式展示，悬停显示详细信息

#### 2.1.5 导出功能
- **图纸导出**:
  - PNG 格式: 可选 1x/2x/4x 尺寸
  - PDF 格式: 包含图纸和色号表
  - 可选包含网格线、色号标注
- **色号表导出**: 图片或 PDF 格式
- **材料清单导出**:
  - TXT 文本格式
  - CSV 表格格式
  - 包含色号、颜色名称、所需数量

## 3. 技术规格

### 3.1 技术栈
- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI框架**: Tailwind CSS + shadcn/ui
- **动画库**: Framer Motion
- **图片处理**: HTML5 Canvas API
- **导出功能**: html2canvas + jsPDF + file-saver

### 3.2 色号数据库
- 内置 Mard 拼豆 291色完整色号库
- 包含: 色号编号、HEX值、RGB值、颜色名称
- 预定义常用48色和常用24色子集

### 3.3 颜色匹配算法
```
欧几里得距离 = √(ΔR² + ΔG² + ΔB²)
```
- 遍历调色板中所有颜色
- 计算与目标颜色的欧几里得距离
- 返回距离最小的颜色

### 3.4 性能优化
- Canvas 离屏渲染
- 图片转换进度反馈
- 虚拟滚动(大号色表)

## 5. 数据结构

### 5.1 核心类型
```typescript
// 色号
interface MardColor {
  code: string;    // 色号编号，如 "A1"
  hex: string;     // HEX值，如 "#FAF4C8"
  r: number;       // 红色通道 0-255
  g: number;       // 绿色通道 0-255
  b: number;       // 蓝色通道 0-255
  name?: string;   // 颜色名称
}

// 像素数据
interface PixelData {
  width: number;
  height: number;
  pixels: MardColor[][]; // 二维数组
}

// 颜色统计
interface ColorStat {
  color: MardColor;
  count: number;
}

// 转换设置
interface ConversionSettings {
  pixelSize: number;     // 32, 48, 64, 96, 128
  colorMode: "all" | "common48" | "common24";
  brightness: number;    // -50 to 50
  contrast: number;      // -50 to 50
  saturation: number;    // -50 to 50
}
```

## 6. 使用流程

### 6.1 正常流程
1. 用户访问网站
2. 上传图片(拖拽或点击)
3. 查看原图预览
4. 选择转换设置(尺寸、色彩模式)
5. 点击"开始转换"
6. 查看像素画预览
7. 查看色号清单
8. 选择导出格式并下载

### 6.2 异常处理
- 图片格式不支持: 提示用户
- 图片加载失败: 提示重新上传
- 转换失败: 显示错误信息
